# SILVAIPTV

Repositorio oficial de distribuicao do aplicativo SILVAIPTV.

- Releases publicados: APK oficial de producao.
- Draft Releases: APKs de teste e backups administrativos, acessiveis ao Worker e colaboradores com permissao de escrita.
- Backups administrativos: criptografados AES-256-GCM e nao publicados.

Nenhuma senha, chave privada, banco de clientes, arquivo .env ou certificado de assinatura deve ser enviado para este repositorio.
